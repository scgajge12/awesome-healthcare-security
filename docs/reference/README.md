## 製薬を独立させている理由

製薬企業のリスクは、治験、製造、供給網という業務の流れに沿って現れる。
システムの種類で切ると、同じ治験データが臨床試験システム、解析環境、委託先の三箇所に分かれて記述が散る。
そのため [技術領域](../technology/) の分類には入れず、業務単位でまとめている。

製造設備の OT は、医療機関側の医療機器と課題が重なる（[医療機器のセキュリティ](../technology/medical-devices/)）。
供給網の論点は、医療機関の委託事業者経由の侵入と同じ構造を持つ（[インシデント事例集](../threats/incidents/)）。
