# 🧰 ツール、論文、研究テーマ、学習リソース、フィード

医療セキュリティの調査と検証で横断して引く参照材を置く。
手を動かすときに使うツール、根拠として引く論文と報告書、どの分野に何の研究があるかの地図、学ぶための講演と教材、事例の候補名を集めるリークサイト横断フィードの五つに分かれる。

> [!NOTE]
> **表記ルール**：本ページでは、**事実**（一次情報で確認できる内容。出典を併記する）と、**分析**（筆者の解釈）を書き分ける。
> 出典は、当事者の公表資料、行政文書、CVE、ベンダアドバイザリなどの一次情報を優先して示す。

## ツールを載せる基準

**分析**：稼働中の医療機器と医療情報システムに向けて動かせるツールは、それ自体が患者の安全に触れる。
[ツール](tools.md)では、掲載したツールを対象への影響で三段階に分け、どの段階のものを隔離環境に限るかを先に示している。
掲載は推奨ではなく、選定と実施の判断は読者の側にある。

検証そのものの進め方は[診断とペネトレーションテスト](../../practice/pentest/)と[医療機器の検証手法](../../technology/medical-devices/testing-methodology.md)に、
書面での許可と実施環境の前提は[トップページの免責事項](../../../README.md#-免責事項)にまとめている。

## 論文と研究テーマを分けている理由

**分析**：[論文、レポート](research.md)は個々の文献の一覧であり、[研究テーマの地図](research-themes.md)はその文献が置かれている分野の構造を示す。
医療のセキュリティ研究は、セキュリティの学会に出るものと、医学および医療情報学の学会に出るものに分かれ、同じ事象を別の問いとして扱う。
文献を一つずつ読む前に、それがどちらの入口から来たものかを知っておくと、査読の基準と結論の射程を読み違えにくい。
