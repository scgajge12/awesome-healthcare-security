# 📅 年ごとの情勢

その年の医療分野に何が起きたかを、国内と海外を一つにまとめて記録する。
個別の事例は地域ごとの履歴に置き、こちらには要点、収録事例の集計、外部統計、規制と制度の動き、前年との差分を置く。

同じ年の国内と海外を並べるのは、被害の型と規制の時間差が、地域を分けた状態では読めないためである。

2019 年以前は年ごとの収録件数に偏りが大きく、地域ごとの `2019-earlier.md`（[国内](../japan/2019-earlier.md)、[海外](../global/2019-earlier.md)）に集約している。
この年代に対応する年ごとのページは置いていない。

収録件数を年で並べた一覧は[インシデント事例集の年別一覧](../README.md#年別一覧)にある。

> [!NOTE]
> 各ページの集計は、断りのない限り**本リポジトリに収録した事例**を母集団とする。
> 発生した被害の全数ではない。
> 年をまたぐ推移を読むときは、収録件数ではなく各ページに挙げた外部統計を根拠にしてほしい。
