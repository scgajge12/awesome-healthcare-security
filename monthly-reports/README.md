# 📅 月報（Monthly Reports）

医療業界のサイバーセキュリティに関する動向を、月単位でまとめる。

## 目的

インシデントもガイドラインの改定も、日々の断片的な情報として流れていく。
月ごとに区切って記録することで、次の三つができるようになる。

1. 医療分野で何が起きたかを、あとから時系列で追える
2. 攻撃の傾向や規制の動きを、月をまたいで比較できる
3. 本リポジトリ本体の更新履歴を残せる

## 作成方法

1. [`_template.md`](_template.md) をコピーする
2. `YYYY/YYYY-MM.md` として保存する（例：`2026/2026-09.md`）
3. 本ページの一覧表に 1 行追加する

## 記載の方針

本リポジトリ全体の[記述の方針](../README.md#-記述の方針)に従う。
月報では特に次の点に注意する。

- **速報性より正確性を優先する**：発生直後の報道には誤りが含まれる。確定した情報と、報道段階の情報を分けて書く。
- **被害組織を批判しない**：公表された事実を記録し、そこから学べることを書く。攻撃を受けたこと自体を責める書き方はしない。
- **未確定の帰属を断定しない**：攻撃グループの特定は、当事者または公的機関の公表に基づく場合のみ記載する。
- **一次情報にリンクする**：報道の見出しではなく、公表資料へのリンクを残す。
